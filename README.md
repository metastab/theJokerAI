# theJokerAI

A fun web app that turns your favorite keywords into custom jokes using AI.

## Features
- **AI Model**: Powered by **Qwen 2.5 (72B)** via Hugging Face for custom, creative punchlines.
- **Offline Engine**: Built-in local template engine that generates jokes without internet access.
- **Quick Topics**: Built-in suggestions to get you laughing right away.
